# 说明书 · Chew Teck Wai 个人网站

这份说明书是按「一年只打开两三次」写的。你不需要懂代码，只需要会两件事：**在文件里搜索一段字**，**把搜到的那段换成别的**。

---

## ① 这个站是什么

一个 HTML 文件，加一个 `assets` 文件夹。样式、交互、文案全在 `index.html` 里；`assets/` 只放了两张二维码图片，是「找到我」那两块二维码用的。不依赖任何外部链接，双击 `index.html` 就能在浏览器里看。改完保存，把文件重新传上去，几分钟后线上就是新的。

文件夹里这些东西分别干这几件事：

| 文件 | 干什么用 |
|---|---|
| `index.html` | **网站本体，所有内容都在这里**。改文案只改它 |
| `assets/avatar-640.webp` | 首屏头像，640×640，46KB。换头像见下面第 2 条 |
| `assets/qr-wechat-2x.png` | 个人微信二维码，336×336。换码就换这个文件，文件名别改 |
| `assets/qr-mp-2x.png` | 公众号二维码，336×336。同上 |
| `README.md` | 你正在看的这份说明书 |
| `DEPLOY.md` | 怎么传到网上、怎么绑自己的域名 |
| `.nojekyll` | 空文件，专给 GitHub Pages 用的。GitHub Pages 默认会让一个叫 Jekyll 的工具先把文件过一遍，这个过程会悄悄丢掉下划线开头的文件；放这个空文件等于告诉它「别处理了，原样发出去」。**别删，也别往里面写字。** |

一句话版本：**一份 HTML · 本地资源 · 零外链 · 双击能开 · 改了重新上传就生效。**

**上传的时候是连同 `assets` 文件夹一起传，不是只传一个 `index.html`。** 只传 HTML 不传图片，二维码那块会显示成破图。

**博客页不是新文件。** 它是 `index.html` 里的第 4 个 hash 视图，和首页、故事、足球写在一起，没有单独的 `blog.html` 要传。

## ② 平时改东西，只需要动这几处

### 先看三条通用规矩

1. **只改中文，不碰尖括号。** `<span class="ct-val">` 这种是壳子，壳子动了页面就会塌。你要改的永远是两个 `>` 和 `<` 之间的那几个字。
2. **改完把 `ph` 删掉。** 占位符的标签里带一个 `ph`，它的作用是让字显示成浅灰色。你把 `【待补：…】` 换成真内容之后，要把同一个标签里的 ` ph`（空格加 ph）删掉，否则新写的字会一直是灰的，看着像还没填。
   例：`<span class="ct-val ph">` → `<span class="ct-val">`
3. **改完自己点一遍。** 双击 `index.html`，把「故事 / 足球 / 博客」三个链接都点一遍，再用手机开一次看。

**现在首屏右侧是一个卡通头像**：`assets/avatar-640.webp`，640×640，单线插画（透明底），放在圆形 `.hero-photo` 框里，显示尺寸 319px。640 是按 2 倍屏算的，正好够 retina。

```html
<img src="assets/portrait.jpg" alt="逆光下侧脸站在球场边" width="420" height="420" decoding="async">
```

### 5. 加一篇博客文章（站内全文，2026-11-14 起）

`#/blog` 是文章列表，`#/blog/<短名>` 是文章详情。**都在同一个 `index.html` 里**，文章正文也写在这个文件里，不新建文件、不接后台。

**加一篇文章 = 在做一件事：往 `<div id="articles" hidden>` 里加一个 `<template>`。**

模板长这样，属性名一个都不能改：

```html
<template data-art="my-first-post" data-title="文章标题" data-date="2021.2" data-desc="一行说明，40 字以内">
  <p>正文第一段。</p>
  <h2>二级标题</h2>
  <p>第二段。</p>
</template>
```

四个属性：

| 属性 | 作用 | 规矩 |
|---|---|---|
| `data-art` | 网址里那截短名，`#/blog/my-first-post` | 只能用小写字母、数字、`-`；**定了就别改**，改了旧链接失效 |
| `data-title` | 列表标题 + 详情页大标题 + 浏览器标签页标题 | 原文照抄 |
| `data-date` | 列表左边那列 | 纯 `YYYY.MM`，别写「发布于」 |
| `data-desc` | 列表里标题下面那行说明 | ≤40 字，一句话 |

**加完不用动别的地方。** 列表是脚本从这个 `<template>` 里读出来生成的，不会出现「详情页有、列表没有」这种不同步。

**正文只允许这些标签：** `p`、`h2`、`h3`、`blockquote`、`ul`、`ol`、`li`、`hr`、`strong`、`em`、`a`、`img`、`code`、`table`、`thead`、`tbody`、`tr`、`th`、`td`。

**正文里不许带的三样东西**（2026-11-14 深夜补，都是实际踩过的）：

1. **公众号模板行**——标题下面的「原创 周周 周周 停不下来的独行侠」「2021年02月22日 22:00」。《30 岁》那篇就带着它上过站，首屏第一眼全是这个。
2. **与标题重复的开头小标题**——文章页已经有 h1 了，正文别再挂一个同名的 h2。
3. **`（一）Where am I from?` 这类分节标志**——要写成 `<h3>`，别留在 `<p>` 里，否则长文是一堵没有落点的墙。

转换器 `_tmp/md2html.py` 已能自动处理第 1、2 条：`python md2html.py 源.md 出.html "文章标题"`（第三个参数传标题，它会把重复的首个小标题删掉）。第 3 条要自己过一遍短段落。

**现已放了 26 篇**（2026-11-15 第三轮扩容，全是你认可的同类型），2020–2026 五个年份分组按日期倒序。选文标准：所思所想、投资理财、AI、学习方法、**工具教程**；不进资助、不进足球。**2026-11-15 改规矩：工具教程解禁进博客**（原「不进纯工具教程」作废，站长拍板）。完整清单在 `index.html` 里搜 `data-art=`。

**资助类和足球类一律不进博客**——本人明确说过。足球要写只能写单篇、不写连载，目前一篇都没有。三篇带图的是 2026-11-15 新写的，图是内联 SVG 信息图（不是照片）：矢量、跟随亮暗主题、每张约 4KB。正文是从公众号导出的 markdown 转来的，**原文配图全部删掉了**——图在 `mmbiz.qpic.cn` 上，有防盗链，直接引用在别人电脑上是裂图。要加图，先把图下载到 `assets/` 再引用。

**列表是自动排的**：脚本按 `data-date` 倒序排，并自动插入年份分组、算「N 分钟」阅读时长（按 400 字/分钟，从正文 `textContent` 现算，不写死在属性里）。所以**只需保证 `data-date` 写对**，顺序和数字都会自己对齐。

**注意标题长度**：文章大标题用的是 `--fs-h2-xl`（32/36/40px），不是首屏那个 56px 的 H1，也不是正文里的 h2。标题超过 20 个字会折成两三行，属于正常。

**不要做的事：** 不要粘 Word/公众号编辑器导出的 HTML（会带一堆 `style=""` 和 `<span>`，把版式搞乱）；不要用 `<div>`、`<font>`；不要加目录、阅读进度、标签、上下篇。

**改文案的六条禁令**（2026-11-14 深夜补，写进 `设计规范.md` H-8，改任何一句话之前先看）：

1. 不写**谦虚式自夸**（「场上最没人夸的那个位置」这种）——表面低调、实为邀功。
2. 不写**元叙述**（「逐条列在下面」）——读者自己会往下看。
3. 不把**校勘说明**放页面上（「按原表逐行转录、依据公开记录补全」）——那是给编辑的，进 HTML 注释。
4. 首屏与 meta 不用**工商全称**（「中国银行股份有限公司」→「中国银行」）。
5. 不写**自证三连**（「纯公益、无广告、不收集个人信息」）——删自我定性，留可验证的承诺。
6. **不要为了省字把句子省坏**（「2005 到 2013 在某某学校」缺谓语）——省字不是文风，是语病。

数字、赛事名、机构名、比分**一个字都不许改**；更不能为了读着顺就把两个事实合并（市运会代表沙坪坝区 ≠ 以重庆队出战）。

**一篇都没有的时候**，`<div id="articles">` 保持空，博客页自动显示 4 条占位。**不要为了填满而编文章**（见第 ③ 节：仓库是公开的，删掉的文字还在提交历史里）。

**短名打错会怎样**：`#/blog/一个不存在的名字` 会自动回落到首页，不会白屏。

## ③ 三条不能破的红线

## ⑤ 禁用词表

改文案的时候，如果写到了下面这些词，**请整句删掉重写**，不要换个说法绕过去。

**通用 13 个（全站都不许出现，包括标题、页面描述、分享卡片文案）：**

**Hero 身份句额外 5 个（只卡首屏那一句话）：**

（前 13 个是《内容清单》的通用禁止表，PRD 6.2 只列了其中前 8 个，这里按全集列；后 5 个是《内容清单》对首屏身份句的额外要求。加起来 18 个。后 5 个只卡身份句——别处写到「专业课」这种正常词是没问题的。）

改完自己搜一遍，**全站应该 0 命中**。

## ⑥ 改完怎么验（机器验收，不靠肉眼）

验收脚本在 `D:\AI工作空间\audit\`，只读，不碰站点文件。**改完 `index.html` 至少跑前三条**：

| 一条命令 | 查什么 | 现在的成绩 |
|---|---|---|
| `node axe.mjs` | 无障碍 · 5 条路由 × 亮/暗 | 10/10 通过，0 违规 |
| `node measure.mjs` | 点击目标 ≥ 44×44 · 桌面/手机 × 4 条路由 | 不合格 0 |
| `node vitals.mjs` | FCP/LCP/CLS、请求数、各文件体积 | FCP 160ms · LCP 160ms · CLS 0 · 2 个请求 · 160KB |
| `node fingerprint.mjs x.json` | 全元素计算样式指纹，用于判断「改动前后渲染是否等价」 | 改前改后哈希一致＝没走样 |
| `npx html-validate index.html` | 语义结构（landmark 重名、h1 为空、th 缺 scope 这类） | 0 error |

为什么用指纹不用截图：站里有进场动画，截图会随等待时间抖动，容易把「动画没播完」看成「样式改坏了」。

**三条会掉分的红线数字**：单文件超过 200KB、请求数超过 4、CLS 大于 0。碰到任何一条，先别加东西，先找是哪段撑大了。

## 附：这个站有意不做的事

不是为了省事，是做了会更差：

- **没有表单、没有评论区。** 表单要有人接待，评论区一年几个人来会变成空房间加垃圾广告。
- **没有访问计数器、没有技能进度条。**
- **不写发布日期、不写「最后更新于」。** 站上没有这类字段，也不需要加。
- **不引外部字体、不引任何第三方脚本。** 页面能不能打开，不取决于别人的服务器今天有没有事。
- **导航当前页不加粗不变色。** 靠位置就够认了。导航共三项：故事 / 足球 / 博客。
